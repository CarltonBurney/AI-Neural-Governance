# Workflows

Step-by-step procedures, with owners, durations, and exit criteria.

| Workflow | Trigger | Output |
|---|---|---|
| [Request Classification](request-classification.md) | Anyone proposes using AI for a business purpose | A tier, a recorded rationale, an inventory entry — target 5 business days |
| [Approval and Launch](approval-workflow.md) | A classified use case enters Gate 2 | A recorded approval with a named signatory, or a documented rejection |

Each workflow closes with the failure modes it is built against — the classification workflow defends against understated autonomy, negotiated-down scoring, and embedded vendor AI never entering intake; the approval workflow defends against post-hoc metric selection, conditional approvals, and deployment without monitoring.
