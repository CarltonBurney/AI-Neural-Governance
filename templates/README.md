# Templates

Operational artifacts referenced by the framework. Each is designed so that completing it honestly is harder than completing it optimistically.

| Template | Used at | Note |
|---|---|---|
| [Intake Form](intake-form.md) | Gate 1 | Asks for autonomy **today and at roadmap end state**, and for populations who are subjects of a decision but not users of the system. Every dimension score requires a written justification — the justification is the auditable artifact, not the number. |
| [Model / System Card](model-card.md) | Gate 4, updated on material change | Requires out-of-scope uses stated positively, and failure modes described as *plausible* failures — confident, well-formed, wrong output is what reviewers must be trained to catch. |
| [Risk Register Entry](risk-register-entry.md) | Continuous | Risk statements must read cause → event → consequence. "Bias" is not a risk statement. Residual risk is accepted by a named individual, never a committee. |

The risk register template ships with six standing entries every T1 system carries by default, beginning with oversight degradation — the failure mode that [Human-in-the-Loop §5](../docs/human-in-the-loop.md) exists to detect.
